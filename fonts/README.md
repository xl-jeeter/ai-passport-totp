# 字体源

`tools/gen_font.sh` 需要一份中文字体（默认读 `fonts/SourceHanSansSC-Regular.otf`）。

字体版权原因不随仓库分发，请自行下载：

```bash
curl -L -o fonts/SourceHanSansSC-Regular.otf \
  https://raw.githubusercontent.com/adobe-fonts/source-han-sans/release/OTF/SimplifiedChinese/SourceHanSansSC-Regular.otf
```

思源黑体（Source Han Sans）采用 SIL Open Font License 1.1。
